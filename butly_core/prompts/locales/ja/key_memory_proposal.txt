以下はAI {agent_name} の「根幹記憶 (Key Memory)」と、最近の「事実ダイジェスト」です。
Key Memory の更新提案を作成してください。

【現在の Key Memory】
{current_key_memory}

【事実ダイジェスト（最新の蓄積）】
{digest_text}

【目的】
Key Memory はユーザーとAIの関係の土台。
半年〜年単位で見直す、ブレてほしくない事実と関係の基盤。
大きな変化があれば提案し、変化がなければ「提案なし」と返す。

【提案ルール】
- 名前、呼称など user_profile で管理される情報は提案しない
- 大きな変化（転職、引っ越し、重要な方針変更）があれば追加を提案
- 古くなった情報があれば削除または更新を提案
- 変化がなければ「提案なし」と返す
- 各提案には理由を1行で添える

【出力形式】
提案がある場合:
ADD [target] 内容
REASON: 理由

REMOVE [target] 削除対象の内容（現在の記載と完全一致で記載）
REASON: 理由

UPDATE [target] 更新前の内容（現在の記載と完全一致で記載） → 更新後の内容
REASON: 理由

提案がない場合:
NO_PROPOSALS
