【根幹記憶 (Key Memory)】
{key_memory}

【目的】
最近の会話の温度感を捉え、応答のニュアンスを補正するための軽いメモ。
事実の記録ではなく、「最近の空気感」を伝えることが目的。

【読み取る情報】
1. 最近の会話トーン（1行）
   - 雑談寄り？開発壁打ちモード？相談モード？

2. 距離感の傾向（1行）
   - 最近は距離近め / 事務寄り / いつも通り

3. 直近の関心事（箇条書き2〜3項目）
   - ユーザーが今最も気にしていること

4. 軽い注意点（あれば1行）
   - 最近の会話で気をつけた方がいいこと

【ルール】
- Key Memory と重複する内容は書かない
- 事実ダイジェストの出来事をそのまま繰り返さない
- 主観的な物語化・脚色は行わない
- {max_chars}文字以内。簡潔さが最優先
- これは「近況メモ」であり「日記」ではない

【出力形式】
# トーン
- ...

# 距離感
- ...

# 関心事
- ...

# 注意点
- ...
